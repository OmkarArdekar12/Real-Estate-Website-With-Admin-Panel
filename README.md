<h2>Description</h2>

<h3>
Real Estate is a full-stack, production-ready real estate showcase platform with an integrated custom Content Management System (CMS) built specifically for dynamic project presentation.<br/> The platform enables real estate companies to manage, update, and publish project content without modifying the source code. It provides a seamless experience for both end users and administrators, ensuring scalable content control, secure access, and cloud-based media management.
</h3>

<h2>Installation Guide</h2>

#### 1. Clone the Repository

```bash
git clone https://github.com/OmkarArdekar12/Real-Estate-Website-With-Admin-Panel
cd Real-Estate-Website-With-Admin-Panel
```

#### 2. Backend Setup

```bash
cd backend
```

```bash
npm install
```

#### 3. Create `.env` file (Inside Backend Folder)

```bash
touch .env
```

```bash
PORT=8080 or your_port_number
MONGODB_URI=your_mongodb_connection_string
CLOUD_NAME=your_cloud_name
CLOUD_API_KEY=your_api_key
CLOUD_API_SECRET=your_api_secret
FRONTEND_URL=http://localhost:3000 or your_frontend_url
NODE_ENV=development
SESSION_SECRET=your_session_secret
ADMIN_EMAIL=your_admin_email
ADMIN_PASSWORD=your_admin_password
```

#### 4. Run Backend Server

```bash
npm run dev
```

#### 5. Frontend Setup

```bash
cd ../frontend
```

```bash
npm i
```

#### 6. Create `.env` file (Inside Frontend Folder)

```bash
touch .env
```

```bash
VITE_API_URL=http://localhost:8080/api or your_backend_api
```

#### 7. Run Backend Server

```bash
npm run dev
```
